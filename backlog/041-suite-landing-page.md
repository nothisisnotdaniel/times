# 041 Suite landing page

As a developer finding the suite, I want one page that shows what Times and Context do, Free against Pro, and how to buy and install, so that I can decide in a minute.

## What

A static GitHub Pages site in this repo's `docs/` (or a `gh-pages` branch): short pitch, screenshots, the Free and Pro table, install steps for the `tm` tool and the unsigned desktop app (linking Context's install guide), and the Lemon Squeezy buy button as a plain link. No scripts from other sites, no tracking.

## Why

Buyers need one place to land from posts and the shop. GitHub Pages costs nothing.
