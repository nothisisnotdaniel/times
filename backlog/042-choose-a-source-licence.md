# 042 Choose a source licence

As the owner of Times and Context, I want to pick a source licence on purpose, so that the public code is clearly allowed to be read and used, but not resold as a copy of the paid suite.

## What

Decide between FSL (Functional Source License, turns Apache 2.0 after two years), MIT or another, then add LICENSE files to Times and Context and a line in each README.

## Why

Times is public with no LICENSE, which means all rights reserved. Before selling Pro, the terms for the code itself should be clear.
